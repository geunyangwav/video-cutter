<h1 align="center">캡컷 컷편집 자동화 도구</h1>

<p align="center">영상을 넣으면 무음 구간과 잔말을 잘라내고, 자막까지 달아서<br>캡컷 프로젝트로 만들어 줍니다.</p>

<p align="center"><sub>effecting · M칩 맥 전용 · 무료 · 영상은 어디에도 업로드되지 않습니다</sub></p>

<br>

카메라를 보고 말하는 영상을 캡컷으로 편집하시는 분들께 추천합니다. 숏폼, 롱폼 모두 쓸 수 있습니다.

저는 이 도구로 매일 컷편집에 쓰던 1~2시간을 줄이고, 그 시간에 다른 부분의 퀄리티를 올리고 있습니다. 저 같은 분들이 계실 것 같아서 무료로 공유합니다.

## 다른 도구와 다른 점

**캡컷에서 바로 이어서 편집할 수 있습니다.** 결과물이 캡컷 프로젝트로 만들어지고, 잘린 부분도 클립 앞뒤를 드래그하면 원본 그대로 다시 살릴 수 있습니다. 다른 도구들은 대부분 자기 편집기 안에서만 작업하거나, 이미 잘린 영상 파일로 내보냅니다.

**무료이고, 사용량 제한이 없습니다.** 내 맥에서 직접 돌아가기 때문에 서버 비용이 들지 않습니다.

**영상이 어디에도 업로드되지 않습니다.** 음성 인식까지 전부 내 맥 안에서 처리합니다. 회사 영상이나 공개 전 영상도 안심하고 쓰셔도 됩니다.

**한국어에 맞춰 만들었습니다.** 음, 어, 그, 저 같은 잔말을 자르고, '생각을 합니다'는 '생각합니다'로 다듬습니다. 아이폰으로 찍은 HDR 영상도 색감이 바뀌지 않습니다.

## 해 주는 일

- 무음 구간을 자릅니다. 숏츠 · 기본 · 여유 중에 고를 수 있습니다.
- 잔말을 자릅니다. 같은 말을 반복한 부분은 자르지 않고 남겨둡니다.
- 음성을 받아 적어서 자막을 자동으로 넣습니다.
- 자막 위치를 알아서 잡습니다. 사람이 나오면 턱 아래, 제품만 나오면 제품을 가리지 않게 위쪽에 둡니다.
- 영상 여러 개를 한 번에 넣으면, 파일 이름 순서대로 이어서 프로젝트 하나로 만듭니다.

## 필요한 것

- **M칩 맥** (인텔 맥과 윈도우에서는 사용할 수 없습니다)
- **캡컷 데스크톱 앱** (설치하고 한 번 실행해 주세요)
- 여유 공간 약 5GB

## 설치 방법

### 방법 1. 터미널에 한 줄 붙여넣기 (추천)

1. 키보드에서 `⌘ + 스페이스`를 누르고 **터미널**을 입력한 뒤 엔터를 누릅니다.
2. 아래 회색 상자 오른쪽의 복사 버튼을 눌러 복사합니다.
3. 터미널 창에 붙여넣고(`⌘ + V`) 엔터를 누릅니다.

```bash
curl -fsSL https://raw.githubusercontent.com/geunyangwav/effecting/main/install.sh | bash
```

4. 5~10분 정도 기다리면 설치가 끝나고 브라우저가 열립니다. 바탕화면에 **effecting** 아이콘이 생깁니다.

관리자 비밀번호는 필요 없습니다.

### 방법 2. 직접 다운로드해서 설치

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼을 누릅니다.
2. 펼쳐진 메뉴 맨 아래 **Download ZIP**을 누릅니다.
3. 다운로드 폴더의 `effecting-main.zip`을 더블클릭해서 압축을 풉니다. (Safari로 받으면 자동으로 풀려 있습니다)
4. `effecting-main` 폴더 안의 **설치하기.command**를 더블클릭합니다.
5. "확인되지 않은 개발자" 경고가 뜨면 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안**에서 맨 아래로 내려 **그래도 열기**를 누릅니다. 그다음 설치하기.command를 다시 더블클릭하고 **열기**를 누릅니다.
6. 터미널 창이 열리면서 설치가 진행됩니다. 끝나면 바탕화면에 **effecting** 아이콘이 생깁니다.

## 사용 방법

1. 바탕화면(또는 Dock)의 **effecting** 아이콘을 더블클릭합니다. 브라우저가 열립니다.
2. 영상을 가운데 상자에 끌어다 놓습니다. 여러 개를 함께 놓으면 프로젝트 하나로 만들어집니다.
3. 결과에 `effecting_1` 같은 이름이 뜨면, 캡컷을 완전히 종료(`⌘ + Q`)했다가 다시 엽니다.
4. 캡컷 프로젝트 목록에서 `effecting_1`을 열고 마무리 편집을 하시면 됩니다.

처음 영상을 넣을 때 폴더 접근 권한을 묻는 창이 뜨면 **허용**을 눌러 주세요.

### 컷 강도

- **숏츠 · 타이트** : 0.25초 이상 쉬면 자릅니다. 빠른 템포의 숏폼에 맞습니다.
- **기본** : 0.35초 이상 쉬면 자릅니다. 호흡이 조금 남습니다.
- **여유** : 0.5초 이상 쉬면 자릅니다. 롱폼이나 브이로그에 맞습니다.

'세부 조정'에서 직접 맞출 수도 있고, 마지막 설정은 저장됩니다.

## 자주 묻는 질문

**캡컷에 프로젝트가 안 보입니다.**
캡컷은 켤 때만 프로젝트 목록을 새로 읽습니다. `⌘ + Q`로 완전히 종료했다가 다시 열어 주세요.

**처음에는 오래 걸립니다.**
처음 받아 적을 때 시간이 걸립니다. 10분 영상 기준 1분 안팎입니다. 같은 영상은 두 번째부터 바로 처리됩니다.

**'반복한 말 · 남겨둠'은 무엇인가요?**
같은 말을 두 번 한 부분입니다. 말버릇일 수도 있고 일부러 한 말일 수도 있어서 자르지 않고 표시만 해 둡니다. 캡컷에서 보고 직접 골라 주세요.

**자막 글꼴은 무엇인가요?**
캡컷에 조선굴림체가 설치되어 있으면 그 글꼴로, 없으면 캡컷 기본 글꼴로 들어갑니다. 캡컷에서 자유롭게 바꾸시면 됩니다.

**업데이트는 어떻게 하나요?**
설치할 때 쓴 명령을 한 번 더 실행하면 최신 버전으로 바뀝니다. 만들어 둔 캡컷 프로젝트는 그대로 남습니다.

**지우고 싶습니다.**
바탕화면의 effecting 아이콘과 홈 폴더의 `effecting` 폴더를 휴지통에 버리면 됩니다. 음성 인식 모델은 홈 폴더의 `.cache/huggingface`에 있습니다.
