## 이런 분께 추천해요

카메라 보고 말하는 **숏폼**을 **CapCut**으로 편집하시는 분.
무음 컷, 잔말 컷, 자막 다는 데 매번 1~2시간씩 쓰고 계셨다면 그 시간을 돌려드려요.

## effecting 만의 자리

- **CapCut으로 편집하는 사람을 위한 도구예요.** 결과가 바로 **CapCut 프로젝트**로 나오고, 잘린 앞뒤를 드래그하면 원본이 그대로 살아나요. 다른 도구는 대부분 자기 편집기에 가두거나, 잘라 낸 영상 파일로 줘요.
- **완전 무료, 사용량 제한 없음.** 내 맥에서 돌아가서 서버 비용이 들지 않아요.
- **영상이 밖으로 안 나가요.** 회사 영상이나 미공개 영상도 안심하고 쓸 수 있어요.
- **한국어 숏폼에 맞춤.** 어/그/저 잔말 컷, '생각을 합니다 → 생각합니다', 턱 아래·제품 위 자막 배치, 아이폰 HDR 색감 유지.

## 해 주는 일

| | |
|---|---|
| ✂️ 무음 컷 | 영상마다 소음 수준을 재서 쉬는 구간을 잘라요 (숏츠 · 기본 · 여유) |
| 🗣️ 잔말 컷 | 음·어·그·저 같은 말버릇을 자르고, '다시 말한 부분'은 표시만 해 둬요 |
| 💬 자동 자막 | 음성 인식(whisper)으로 받아써서 짧은 숏폼 자막으로 넣어요 |
| 📍 자막 위치 | 인물 영상은 턱 아래, 제품만 나오는 영상은 제품을 가리지 않게 위쪽에 |
| 🎞️ 여러 영상 | 함께 놓은 영상들은 파일 이름 순서대로 **프로젝트 하나**로 이어 붙여요 |
| 🎨 원본 색감 | 아이폰 HDR 영상도 CapCut에서 직접 가져온 것과 같은 색으로 |

## 필요한 것

- **M칩(Apple Silicon) 맥** — 인텔 맥, 윈도우는 안 돼요
- **CapCut 데스크톱 앱** — 설치하고 한 번 실행해 두세요
- 저장 공간 약 5GB (음성 인식 모델 포함)

## 설치

**터미널**(⌘ + 스페이스 → '터미널')을 열고, 아래 한 줄을 붙여넣고 엔터:

```bash
curl -fsSL https://raw.githubusercontent.com/geunyangwav/effecting/main/install.sh | bash
```

5~10분 뒤 바탕화면에 **effecting** 아이콘이 생겨요. 관리자 비밀번호는 필요 없어요.

<details>
<summary>터미널이 낯설다면 — 다운로드해서 더블클릭으로 설치</summary>

1. 이 페이지 위쪽 초록색 **Code → Download ZIP**
2. 압축을 풀고 폴더 안의 **설치하기.command** 를 더블클릭
3. 맥이 "확인되지 않은 개발자" 라며 막으면 → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **'그래도 열기'** → 다시 더블클릭

</details>

## 사용법

1. 바탕화면(또는 Dock)의 **effecting** 아이콘 더블클릭 → 브라우저가 열려요
2. 영상을 가운데 상자에 **끌어다 놓기** (여러 개를 함께 놓으면 프로젝트 하나로)
3. 결과 카드에 `effecting_1` 같은 이름이 뜨면, **CapCut 을 완전히 종료(⌘Q)했다가 다시 열기**
4. CapCut 프로젝트 목록의 `effecting_N` 을 열어 마무리 편집

> 처음 영상을 넣을 때 '문서 폴더 접근' 같은 권한 창이 뜨면 **허용**을 눌러 주세요.

### 프리셋

| | 이만큼 쉬면 자름 | 말 끝 여유 | 이런 영상에 |
|---|---|---|---|
| **숏츠 · 타이트** | 0.25초 | 0.02초 | 쉼 없이 빠른 숏폼 |
| **기본** | 0.35초 | 0.06초 | 자연스러운 호흡 |
| **여유** | 0.5초 | 0.15초 | 롱폼, 브이로그 |

'세부 조정'에서 직접 맞출 수도 있고, 마지막 설정은 기억돼요.

## 자주 묻는 것

**CapCut 에 프로젝트가 안 보여요** — CapCut 은 켤 때만 목록을 새로 읽어요. ⌘Q로 완전히 종료했다가 다시 열어 주세요.

**처음엔 느려요** — 영상 내용을 처음 받아쓸 때 시간이 걸려요(10분 영상에 1분 안팎). 같은 영상은 두 번째부터 바로 돼요.

**자막 글꼴** — CapCut 에 '조선굴림체'가 설치돼 있으면 그걸 쓰고, 없으면 CapCut 기본 글꼴로 나와요. CapCut 안에서 자유롭게 바꾸면 돼요.

**'다시 말함?' 표시** — 같은 말을 반복한 부분은 일부러 자르지 않았어요. CapCut 에서 보고 골라 주세요.

**업데이트** — 설치 명령을 한 번 더 실행하면 최신 버전으로 바뀌어요. 만들어 둔 CapCut 프로젝트는 그대로예요.

**지우고 싶어요** — 바탕화면의 effecting 아이콘과 홈 폴더의 `effecting` 폴더를 휴지통에 버리면 끝이에요. (음성 인식 모델은 `~/.cache/huggingface` 에 있어요)
